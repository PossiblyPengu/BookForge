Pageturner

Install the iOS app straight from this page — no computer.

1 · Register this iPhone

Apple doesn't expose the device UDID to websites. Install this tiny profile once — it hands the UDID back to this page and deletes nothing (it's unsigned, so iOS will warn; that's expected).

Download device profile
  1. Tap Allow on the profile download prompt
  2. Settings → Profile Downloaded → Install
  3. You'll land back here with the UDID filled in
  4. Then delete the profile: Settings → General → VPN & Device Management

2 · Sign with your Apple ID

Install Pageturner

iOS will ask to confirm, then installs like any App Store app. Enable Developer Mode if you haven't: Settings → Privacy & Security → Developer Mode.

Notes

Free Apple IDs get a 7-day certificate. When the app stops opening, come back here and run the same form again — your UDID and App ID are already registered, so it's password → install, about a minute. Your data carries over.

The password is sent only to this site's dispatch endpoint and into the signing run — it is never stored. The passphrase and Apple ID live in this browser's localStorage.
